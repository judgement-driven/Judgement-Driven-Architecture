# 3. Judgement Delegation Canvas（JDC）

## Case: 株式会社文化アディック

### J07 入金確認・消込ジャーニー

------------------------------------------------------------------------

## 1. 本ケースの位置づけ

本ドキュメントは、\
Judgement Driven Architecture（JDA）フェーズ3\
Judgement Delegation Canvas（JDC）を\
株式会社文化アディックの入金消込業務へ適用した記録である。

本工程の目的は、

> 判断の責任構造を明確化すること

である。

ここでは以下を行わない。

- 改善設計
- 業務最適化
- 自動化前提設計
- AIによる代替設計

あくまで、

> 「誰が何を確定させる判断なのか」を固定する

ことに集中する。

------------------------------------------------------------------------

## 3. 使用プロンプト

### 3.1 概要

生成AIへ以下を入力した。

- JDA README
- フェーズ1で抽出したJudgement Point一覧
- 各判断点の現状業務内容
- 「改善せず、責任構造のみ整理せよ」
- 「AI関与方針は段階的に示せ」
- 「最終責任主体を明示せよ」

------------------------------------------------------------------------

### 3.2 再現用プロンプトサンプル

``` text
あなたはJudgement Driven Architecture（JDA）の設計補助エージェントである。

以下はフェーズ1で抽出したJudgement Pointである。
（JP-02、JP-03、JP-05の内容を貼付）

目的はフェーズ3（JDC）である。

改善設計をせず、
最適化せず、
責任構造の明確化のみを行え。

各Judgement Pointについて以下を整理せよ。

1. 判断内容（何を確定させる判断か）
2. 現在の判断主体（As-Is）
3. 判断材料
4. 属人性の程度
5. AI関与方針（段階的）
6. 最終責任主体

出力はMarkdown形式とする。
```

## 4. Judgement Delegation Canvas

------------------------------------------------------------------------

## JP-02 消込可否判断

### 判断内容

入金情報と請求情報を照合し、

- 消込可能\
- 消込不可（例外処理へ）

を確定させる判断。

------------------------------------------------------------------------

### 現在の判断主体（As-Is）

- 経理担当（一次判断）

------------------------------------------------------------------------

### 判断材料

- 入金金額
- 請求金額
- 入金名義
- クライアント名
- 案件情報
- 売上管理台帳

------------------------------------------------------------------------

### 属人性

中。

- 基本はルール照合
- 微差・曖昧一致で判断揺れあり

------------------------------------------------------------------------

### AI関与方針（段階的）

#### 段階1：材料整理

- 金額自動照合
- 名義一致度スコア算出

#### 段階2：履歴提示

- 過去類似消込結果提示

※ 最終確定は経理担当

------------------------------------------------------------------------

### 最終責任主体

- 経理担当

------------------------------------------------------------------------

## JP-03 差異許容判断

### 判断内容

差異がある場合に、

- 許容して消込するか
- 営業確認へ回すか
- 上位者へ委任するか

を確定する判断。

------------------------------------------------------------------------

### 現在の判断主体

- 経理担当（一次判断）
- 営業担当（確認時）
- 営業管理者
- 専務／社長（例外時）

------------------------------------------------------------------------

### 判断材料

- 差額規模
- 名義一致度
- 過去履歴
- 顧客規模
- 案件重要度

------------------------------------------------------------------------

### 属人性

高。

- 明文化基準なし
- 経営判断依存あり

------------------------------------------------------------------------

### AI関与方針（段階的）

#### 段階1：差異構造化

- 差額要素の構造化表示
- 過去類似事例提示

#### 段階2：推奨案提示

- 推奨対応案提示

※ 最終確定は必ず人

------------------------------------------------------------------------

### 最終責任主体

- 許容確定 → 経理担当\
- 委任確定 → 上位者

------------------------------------------------------------------------

## JP-05 督促要否判断

### 判断内容

支払期限超過案件について、

- 待機
- 営業督促
- 強化督促

を確定する判断。

------------------------------------------------------------------------

### 現在の判断主体

- 経理担当
- 営業担当
- 専務／社長（強化時）

------------------------------------------------------------------------

### 判断材料

- 期限超過日数
- 過去入金傾向
- 顧客関係性
- 金額規模

------------------------------------------------------------------------

### 属人性

中〜高。

------------------------------------------------------------------------

### AI関与方針（段階的）

#### 段階1：材料整理

- 超過日数算出
- 過去督促履歴提示

#### 段階2：強度推奨

- 督促強度の推奨提示

※ 経営判断は人

------------------------------------------------------------------------

## 5. 本工程で確定したこと

- 判断の責任移動構造が明示された
- AIは支援から開始する方針とした
- ログ設計対象が明確化された
- 判断ごとの最終責任主体が固定された
