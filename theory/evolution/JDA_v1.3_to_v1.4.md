# JDA v1.3 → v1.4 変更経緯

TYPE: Evolution Note  
PROJECT: JDA Core  
VERSION: v1.4  
DATE: 2026-04-14  

---

## 1. 背景

JDA Core v1.3は、以下の再定義を行った。

- 「判断の連鎖」から「状態遷移」への構造転換
- Case / State / JPによる実行モデルの定義
- Learning Loopによる遷移関数の学習

これにより、JDAは

> 状態遷移と学習構造を持つアーキテクチャ

として整理された。

しかし、実装（Phase5）を進める中で、  
v1.3では未定義であった重要な論点が明確になった。

---

## 2. 問題意識

実装を通じて、以下の違和感が発生した。

### 2.1 Learningの到達点が不明確

v1.3ではLearning Loopは定義されていたが、

- 何をもって「学習完了」とするのか
- 学習の結果、何が起きるのか

が明示されていなかった。

---

### 2.2 AIの役割が途中で止まっている

v1.3ではAIの役割は以下に限定されていた。

- 判断支援
- 選択肢提示
- 類似事例提示

しかし、

> 学習したAIが判断そのものを担うかどうか

が定義されていなかった。

---

### 2.3 実装上、判断の再現性が見え始めた

JP単位の実装を進めた結果、

- 同じ条件・観点で同じ判断が繰り返される
- 判断パターンがJLogとして蓄積される

という事実が確認された。

これは、

> 判断は学習可能であり、再現可能である

ことを意味する。

---

## 3. 仮説

上記を踏まえ、以下の仮説を導出した。

### 仮説1

JDAのLearningは、

> 判断の再現を可能にする構造である

### 仮説2

判断の再現が可能であるならば、

> 判断はAIに委譲可能である

### 仮説3

JDAの最終形は、

> 人間の判断をAIが代替する状態（委譲）である

---

## 4. v1.4での変更内容

上記仮説に基づき、JDA Coreを以下のように拡張した。

---

### 4.1 Learning Loopの2段階化

従来：

```text
Data → AI → Options → Human → JLog → Action → Result → VLog → Learning
```

変更後：

【支援段階】

```text
Data → AI → Options → Human → JLog → Action → Result → VLog → Learning
```

【委譲段階】

```text
Data → AI（JLog学習済） → Decision → Human Review → JLog → Result → VLog → 精度向上
```

---

### 4.2 判断AIエージェントの役割拡張

従来：

- 判断支援
- 選択肢提示
- 判断分析

変更後：

- 判断支援（初期段階）
- 選択肢提示・ランキング（中期段階）
- 判断代替・自動確定（委譲段階）

---

### 4.3 委譲条件の明確化

判断の委譲は以下の条件を満たす場合に行う。

- JLogが一定量蓄積されている
- VLogにより妥当性が確認されている
- 人間が委譲を承認している

---

### 4.4 JSC注記の削除

v1.3では以下の記述が存在した。

> JSCの完全再定義はv1.4で実施する

実装により、

- JPが遷移定義の主構造
- JSCは補助レイヤー

として十分機能することが確認されたため、  
再定義は不要と判断し削除した。

---

## 5. 変更の意味

今回の変更により、JDAは以下の統合構造を持つ。

```text
State Machine
+ JLog
+ VLog
+ Learning Loop
```

さらに、

```text
判断支援 → 判断再現 → 判断委譲
```

という進化パスが明示された。

---

## 6. CoreとMethodの関係

本変更はCoreの拡張であり、  
Method（Phase0〜6）の手順には変更を与えない。

理由：

- 実装プロセスは変わらない
- 学習フェーズ（Phase6）は未実施である
- 委譲は将来段階のため

---

## 7. 今後の検証ポイント

v1.4の正当性は以下で検証される。

- JLogが十分に蓄積されるか
- VLogにより判断精度を評価できるか
- 特定JPにおいて委譲が成立するか
- 人間レビューで破綻しないか

---

## 8. 結論

JDA v1.4は、

> 判断を学習し、最終的に委譲可能にするアーキテクチャ

として再定義された。

これは、単なる判断支援システムではなく、

> 企業の意思決定そのものを再現・進化させる仕組み

への拡張である。
